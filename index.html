In useDesign · Production

Automatic manufacturing drawings

ProblemEvery cabinet needed a drawing for the shop floor. The engineer drew them by hand in SolidWorks, slowly, and mistakes reached production.
BuiltTwo generators that make the same kind of sheet with no manual drafting. One is inside the cabinet creator. The other works on full kitchens modelled in SolidWorks.
What a sheet contains
  • Front, without-fronts and side views at 1:15, with front dimensions in bold and gaps marked separately
  • Parts table with material and edgebanding, plus a hardware list (runners, legs, connectors)
  • Assembly diagram with numbered balloons that match the parts table
  • Room plan and wall elevations for the whole kitchen, then one sheet per cabinet, as one PDF
  • Colours by role so shop-floor staff read a sheet at a glance. I tested and rejected transparent and wireframe styles as hard to read

In useShop floor · CNC router

A new operator interface for an old CNC

ProblemOur CNC router runs closed control software on a touch-only Windows XP PC built into the machine. The screens were hard to read, the vendor gives no support, and the operator couldn't see the program being cut.
BuiltA complete new skin for the control software, and a companion program that shows the job live, without changing a single line of the vendor's code.
How it works
  • Read the layout of every screen out of the compiled program, so each new button lines up exactly with the touch area it replaces
  • Redrew all screens from one design system and rendered them into the exact image files the software loads: clearer type, higher contrast, tidied English messages
  • NLNCView, a small C program that runs on the old Pentium PC with no runtime. It shows the loaded program over the jog keys and follows the file the operator selects
  • Tracks the tool live by reading the coordinates the controller already shows, then draws the board being carved in 3D in real time
  • Installs with numbered one-tap scripts and an undo, because the machine has no keyboard. It never touches Windows start-up settings after one of them broke boot
